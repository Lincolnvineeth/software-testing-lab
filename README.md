# Software Testing Lab — Python Calculator

A beginner-friendly software testing project built in Python using pytest.
This project demonstrates core software testing techniques applied to a 
simple calculator module, with automated test execution via GitHub Actions.

## Testing Techniques Covered
- **Unit Testing** — testing each function individually
- **Boundary Value Analysis** — testing edge cases like 0, -1, and invalid inputs
- **Black-Box Testing** — testing based on input/output without looking at internal logic
- **Regression Testing** — re-running all tests after every code change via CI

## Project Structure
calculator.py        # Source code being tested
test_calculator.py   # All test cases
report.html          # Auto-generated test report
.github/workflows/   # GitHub Actions CI pipeline

## How to Run Tests Locally
pip3 install pytest
python3 -m pytest test_calculator.py -v

## Tools Used
- Python 3
- pytest
- GitHub Actions (CI/CD)
- VS Code
